### Top findings

1. Engines ship two units, not one. A copied starter that the game owns (template, sample). A versioned system that the vendor owns (package, plugin). Unity copies samples into `Assets` [S10](https://docs.unity.com/en-us/engine/6000.0/manual/packages-list/cus-pkg-development/cus-samples). Godot splits "Templates" from assets placed into a project [S15](https://docs.godotengine.org/en/latest/community/asset_store/what_is_asset_store.html). Unreal has templates [S5](https://www.unrealengine.com/news/updated-game-templates-for-unreal-engine-5-6available-now) and Game Feature plugins [S3](https://dev.epicgames.com/documentation/en-us/unreal-engine/game-features-and-modular-gameplay-in-unreal-engine). VERIFIED (Unity, Godot, GF) / REPORTED (templates). SHIPPED.
2. Unreal loads agent skills from each enabled plugin. "A folder that contains a SKILL.md file is a skill." Folders: `<Plugin>/Skills/` in every enabled plugin, `<Project>/Skills/`, `Engine/Extras/AgentTools/Skills/` [S1](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-mcp-in-unreal-editor). VERIFIED. ANNOUNCED (experimental). Closest engine precedent for option C. But the host routes, not a hand-written router skill.
3. Unreal MCP hides tools behind search by default (`bEnableToolSearch = true`): `list_toolsets` → `describe_toolsets` → `describe_tools` → `call_tool`. This "keeps tools/list responses small even with hundreds of tools" [S1](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-mcp-in-unreal-editor). VERIFIED. ANNOUNCED. No token numbers given.
4. Roblox Studio has a built-in MCP server with about 31 tools. It includes a `skill` tool, `http_get` limited to Roblox docs, Creator Store `search_asset`/`insert_asset`, and playtest plus input-simulation tools [S12](https://create.roblox.com/docs/studio/mcp.md). VERIFIED. SHIPPED.
5. Unity's MCP ships inside the AI Assistant package (2.7.0-pre.3, Unity 6+). New clients wait in "Pending Connections" until accepted [S8](https://docs.unity3d.com/Packages/com.unity.ai.assistant@2.7/manual/integration/unity-mcp-get-started.html). "Unity's AI tools are available in beta for all Unity 6 developers" [S9](https://unity.com/blog/mcp-servers-game-development). VERIFIED. ANNOUNCED (beta).
6. Unity Multiplayer Center maps game type to a package set. Essentials cannot be deselected. It installs, then shows a Quickstart that changes with the picks [S6](https://docs.unity.com/en-us/multiplayer/multiplayer-center.md). VERIFIED. SHIPPED.
7. Roblox Packages are linked copies that auto-update until edited: "Automatic updating does not apply to modified package copies." [S13](https://create.roblox.com/docs/projects/assets/packages.md). VERIFIED. SHIPPED.
8. SpacetimeDB ships 11 agent skills split by layer and language, not by feature [S21](https://github.com/clockworklabs/SpacetimeDB/tree/master/skills). The `concepts` skill is always-on in Cursor (`cursor_always_apply: true`) and points to the language skills [S22](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/skills/concepts/SKILL.md). VERIFIED. SHIPPED.
9. Photon's llms.txt gives agents version rules. Record the version from the final URL. Do not generate code from older versions unless the project is pinned to them [S25](https://doc.photonengine.com/llms.txt). VERIFIED. SHIPPED.
10. Big sample games go stale. Unity's Boss Room is "no longer being actively maintained" as of 2026 and may not work with the latest NGO or Unity [S11](https://docs.unity3d.com/Packages/com.unity.netcode.gameobjects@2.10//manual/samples/bossroom/bossroom-landing.html). REPORTED. SHIPPED.
11. Godot and Bevy ship no official agent tooling. Every Godot MCP server found is community-made [S17](https://mcpservers.org/servers/Coding-Solo/godot-mcp). Bevy's linter is "unofficial right now" [S18](https://bd103.dev/blog/2025-09-09-bevys-5th-birthday). REPORTED (Godot) / VERIFIED (Bevy).
12. Agent success data is thin. The only vendor number found: SpacetimeDB's own one-shot benchmark, 91.7% average vs 62.7% for PostgreSQL over 13 runs. The summary page does not state the method [S23](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/docs/llms/oneshot-summary.md). VERIFIED. RESEARCH (vendor-run).

## Q1. Unit of reuse, dependency vs copy, ownership

### Takeaway
Each engine has a copied starter (game owns it) and a versioned system (vendor owns it). Options A, B and C each cover only one of the two.

### Cited Findings
- **Unity (official).** Samples are declared in `package.json` `samples` (`displayName`, `description`, `path`) under `Samples~`. On Import, "the Package Manager copies the whole subfolder structure for that sample under the project's `Assets` folder" [S10](https://docs.unity.com/en-us/engine/6000.0/manual/packages-list/cus-pkg-development/cus-samples). Package code stays a dependency: the Multiplayer Center "installs these packages and their dependencies" [S6](https://docs.unity.com/en-us/multiplayer/multiplayer-center.md). VERIFIED. SHIPPED.
- **Unreal (official).** A Game Feature plugin lives under `/Plugins/GameFeatures/`. Its `GameFeatureData` asset holds Actions: Add Components, Add Cheats, Add Data Registry, Add Data Registry Source, Add World Partition Content [S3](https://dev.epicgames.com/documentation/en-us/unreal-engine/game-features-and-modular-gameplay-in-unreal-engine). VERIFIED. SHIPPED.
- **Unreal templates.** UE 5.6 added genre variants. First Person: Arena Shooter, Survival Horror. Third Person: Combat, Side Scroller, Platformer [S5](https://dev.epicgames.com/documentation/unreal-engine/variants-in-game-templates). REPORTED. SHIPPED.
- **Godot (official).** The Asset Store beta opened in June 2025 with ~50 free assets [S16](https://gameworldobserver.com/2025/06/26/the-beta-version-of-the-asset-store-for-the-godot-engine-has-been-released) (REPORTED). In May 2026: "The new Asset Store is live and stable and will be fully integrated in Godot 4.7" [S14](https://godotengine.org/article/introducing-the-godot-asset-store/) (VERIFIED). Templates appear in the Project Manager and run as standalone projects. Other assets are "meant to be downloaded and placed into an existing Godot project" [S15](https://docs.godotengine.org/en/latest/community/asset_store/what_is_asset_store.html). VERIFIED. Conflict: the 4.7 docs still say "the Asset Store is currently in beta" [S15].
- **Roblox (official).** A Package is a group of instances. Copies link back through a `PackageLink`. "Ownership transfers are **not** supported by the asset system" [S13](https://create.roblox.com/docs/projects/assets/packages.md). VERIFIED. SHIPPED.
- **Bevy (official guidance).** Plugins are crates. Authors should add a README table mapping each Bevy version to a plugin version. Set `default-features = false` because "Features are additive". Dual MIT/Apache license. Publish to crates.io and Bevy Assets [S20](https://bevy.org/learn/quick-start/plugin-development/). VERIFIED. SHIPPED.

### Inferences
- Option A is a "starter" unit. B and C are "system" units. Every engine ships both.
- Who owns the code decides how updates arrive (Q2).

### Gaps
- Unity's exact sample folder (per-version subfolders?) and what happens on package update are not on S10.

## Q2. Updates and breaking changes

### Takeaway
Dependencies get updates. Copies do not. Even Roblox's auto-update stops at the first edit.

### Cited Findings
- **Roblox.** AutoUpdate runs when a place opens in Studio. "Automatic updating does not apply to modified package copies." Editing disables AutoUpdate until publish or revert. Mass update "automatically saves the selected places but does not publish them." Per-copy configuration attributes survive updates. Scripts in unmodified packages are read-only until unlocked. Versions can be viewed and restored [S13](https://create.roblox.com/docs/projects/assets/packages.md). VERIFIED. SHIPPED.
- **Unity.** On projects that already have multiple multiplayer packages, the Multiplayer Center "installs or upgrades the selected packages but doesn't remove existing packages. This can cause compatibility issues." [S6](https://docs.unity.com/en-us/multiplayer/multiplayer-center.md). VERIFIED.
- **Bevy.** Plugins either track `main` (pin a `rev`) or releases. Badges show which [S20](https://bevy.org/learn/quick-start/plugin-development/). VERIFIED. bevy_lint ships a new release per Bevy version: v0.5.0 for Bevy 0.17, v0.6.0 for Bevy 0.18 on nightly-2026-01-22 [S19](https://github.com/TheBevyFlock/bevy_cli/releases). REPORTED.
- **Godot.** Moving from Asset Library to Asset Store was manual: "All authors must re-upload their assets to the new store" [S15](https://docs.godotengine.org/en/latest/community/asset_store/what_is_asset_store.html). The Library "will be set as a read-only repository in the near future". Store assets can have several downloadable versions and a changelog page [S14](https://godotengine.org/article/introducing-the-godot-asset-store/). VERIFIED.
- **Photon.** The llms.txt tells agents to record versions and pin. It names preview products (Fusion for Unreal/Godot, Realtime Core, Quantum 3.1 preview) [S25](https://doc.photonengine.com/llms.txt). VERIFIED.
- **SpacetimeDB.** Skill rule: "Changing the canonical namespace drops its tables and their data, so pin it when renaming an accessor." C# module composition needs 2.13+, nested mounts 2.14+ [S22](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/skills/concepts/SKILL.md). VERIFIED. A `spacetimedb-migration-2.0.mdc` Cursor rule exists [S24](https://git.adamlamers.com/PublicArchive/SpacetimeDB/commits/branch/master/docs/llms). REPORTED.
- **Unreal MCP.** "APIs and data formats may change at any time." A new `UFUNCTION` needs a full editor restart [S1](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-mcp-in-unreal-editor). VERIFIED.

### Inferences
- When an agent edits copied system code, the game forks. The best automatic path found (Roblox) still stops at the first edit.
- Vendors now ship migration and version rules as agent material (Photon, SpacetimeDB).

### Gaps
- How Game Feature plugins and Lyra are versioned across engine releases: not found.

## Q3. Guardrails shipped with systems

### Takeaway
Guardrails are mostly structural: read-only code, locked essentials, approval prompts, per-tool access modes. Plus rules inside skills. No engine ships tests that pin gameplay-system rules.

### Cited Findings
- **Roblox.** Package scripts are read-only until unlocked. There is a diff tool. Docs warn that unfamiliar assets may hold malicious scripts [S13](https://create.roblox.com/docs/projects/assets/packages.md). MCP: "MCP clients can read and modify content in your open Roblox places. Make sure to only connect clients you trust." Every call needs a `studio_id`. Code tools need a `datamodel_type`. `http_get` only reaches allowed Roblox doc URLs [S12](https://create.roblox.com/docs/studio/mcp.md). VERIFIED. SHIPPED.
- **Unreal MCP.** Loopback-only. No authentication: "don't expose the server beyond the local machine". `AIAccessMode` per tool ("set it on every tool"). Cooked builds expose only `AIRuntimeCallable` tools. Tool calls run one at a time on the game thread. Tool categories include automation tests and profiling [S1](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-mcp-in-unreal-editor). VERIFIED. ANNOUNCED.
- **Unreal Game Features.** Add Components on the base Actor class "is unsupported". Actors must register with `UGameFrameworkComponentManager` (`AddReceiver`) to receive components. Cheat extensions do not exist in Shipping builds [S3](https://dev.epicgames.com/documentation/en-us/unreal-engine/game-features-and-modular-gameplay-in-unreal-engine). VERIFIED.
- **Unity.** Essential packages cannot be deselected [S6](https://docs.unity.com/en-us/multiplayer/multiplayer-center.md). MCP clients need approval [S8](https://docs.unity3d.com/Packages/com.unity.ai.assistant@2.7/manual/integration/unity-mcp-get-started.html). VERIFIED.
- **Bevy.** bevy_lint is modeled on Clippy. v0.1.0 had 6 lints. Releases followed in Mar, Apr and Aug 2025. Community-run (TheBevyFlock) [S18](https://bd103.dev/blog/2025-09-09-bevys-5th-birthday). VERIFIED. SHIPPED (unofficial).
- **SpacetimeDB.** The concepts skill has "Critical Rules": reducers are deterministic (no filesystem, network, clocks, randomness); use `ctx.sender`; auto-increment IDs are not for ordering. Plus a 5-step "Feature Implementation Checklist" [S22](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/skills/concepts/SKILL.md). VERIFIED.
- **Quantum.** The simulation "allocates no C# heap memory at runtime and creates no garbage". Systems are stateless [S26](https://doc.photonengine.com/quantum/current/quantum-intro.md). VERIFIED.

### Inferences
- I found nothing like Echo's per-system tests plus mutation checks in any engine's reusable systems. Rules live in skills and API shape instead.

### Gaps
- Unreal Data Validation, Unity package validation, and Quantum desync/checksum tools were not read.

## Q5. Picking systems by game type

### Takeaway
Two shipped patterns: a recommender over packages (Unity) and genre template variants (Unreal). Neither is "one template with every system."

### Cited Findings
- **Unity Multiplayer Center table.** Casual co-op → Netcode for GameObjects + Transport. Competitive → Unity Netcode (`com.unity.netcode`) + Transport + "a server hosting service of your choice". Turn-based → Cloud Code. Each row also lists the Multiplayer Services SDK and test tools. Picks update live. Essentials cannot be deselected. "The content in the **Quickstart** tab might change based on the recommendations you selected" [S6](https://docs.unity.com/en-us/multiplayer/multiplayer-center.md). VERIFIED. SHIPPED.
- Unity 6.6 alpha docs: pick a genre; "Essentials" vs optional "Recommended" [S7](https://docs.unity3d.com/6000.6/Documentation/Manual/multiplayer-center.html). REPORTED. ANNOUNCED.
- Unreal 5.6 genre variants [S5](https://dev.epicgames.com/documentation/unreal-engine/variants-in-game-templates). Forum users said the Arena Shooter variant shipped missing assets [S5]. REPORTED.
- Roblox agents can search and insert Creator Store assets through MCP [S12](https://create.roblox.com/docs/studio/mcp.md). VERIFIED.

### Inferences
- The Multiplayer Center is a B-style router with C-style packages under it. It is data (a table), not prose.

## Q6. Unreal Game Features and Lyra

### Takeaway
Game Feature plugins are opt-in modules. They inject components, data and abilities into a core game through data. A game turns features on by listing them.

### Cited Findings
- Game Features help "create standalone features" and avoid unintended dependencies between unrelated features, which matters for live products [S3](https://dev.epicgames.com/documentation/en-us/unreal-engine/game-features-and-modular-gameplay-in-unreal-engine). VERIFIED.
- Components added by a feature should come from the plugin. Keep required interaction with project Actor subclasses minimal, so the feature can be reused in other projects [S3]. VERIFIED.
- A Lyra Experience Definition holds default Pawn Data, Game Feature Actions, Action Sets, and Game Feature plugin dependencies. Loading an experience loads those plugins. The game mode runs all actions before it broadcasts "experience loaded" [S4](https://x157.github.io/UE5/LyraStarterGame/Experience). REPORTED. Lyra is older (2022) background.

### Inferences
- For a catalog, the core needs a small stable extension surface (receivers, registries), and each game declares a feature list. In Cardinal terms: a per-game list of plugins, each adding its own systems and components. The core never imports features.

### Gaps
- Feature states (installed/registered/loaded/active) and an explicit "core must not reference features" rule were not on the page I read. Lyra's official pages returned empty to my fetch.

## Q7. Multiplayer frameworks

### Takeaway
They ship starters, samples, and agent-readable docs. Only SpacetimeDB ships agent skills and a benchmark. Quantum's shared deterministic simulation is the closest match to Echo's wasm prediction.

### Cited Findings
- **Colyseus 0.18.** Starter: `npm create colyseus-app`. llms.txt plus raw Markdown per page. No MCP and no rules files [S27](https://docs.colyseus.io/llms.txt). VERIFIED. A community docs MCP exists [S28](https://glama.ai/mcp/servers/VGFP/colyseus-docs-mcp/schema). REPORTED.
- **SpacetimeDB.** 11 skill folders: cli, concepts, cpp-server, csharp-client, csharp-server, mcp, rust-server, typescript-client, typescript-server, unity, unreal [S21](https://github.com/clockworklabs/SpacetimeDB/tree/master/skills). Reusable modules: "TypeScript and C# support same-language submodule composition". Modules are listed at spacetimedb.com/modules [S22](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/skills/concepts/SKILL.md). The concepts skill is long (fetch tool estimate ~2,600 words). VERIFIED.
- **Nakama/Hiro.** Hiro is "A Nakama toolkit to rapidly build standardized meta game features". About 20 top-level entries: Achievements, Economy, Energy, Inventory, Event Leaderboards, Progression, Streaks, Teams, Unlockables and more. Client SDKs: Unity, Unreal, C++, Dart, TypeScript, Godot, Python. Has a "GDD Templates" page [S29](https://heroiclabs.com/docs/hiro/). VERIFIED. llms.txt and llms-full.txt exist [S30](https://heroiclabs.com/llms.txt). REPORTED. No official MCP found.
- **Photon.** The llms.txt routes Unity users to Fusion 2 and tells agents to name preview status [S25](https://doc.photonengine.com/llms.txt). Quantum 3: game logic is "an isolated, pure C# simulation, using the Quantum ECS, which is decoupled from Unity". Clients exchange only input and predict plus roll back locally. The server is "game-agnostic". Systems are stateless. A DSL generates the data code. "There are many Game Samples to download" [S26](https://doc.photonengine.com/quantum/current/quantum-intro.md). VERIFIED.
- **Unity Netcode samples.** Boss Room is unmaintained (last release 2.5.0, Apr 2024). The Bitesize repo keeps a "Deprecated" folder [S11](https://github.com/Unity-Technologies/com.unity.multiplayer.samples.coop/releases). REPORTED.

### Inferences
- For code shared by server and client: keep the simulation package free of view and client types (Quantum). Put determinism rules in the always-on skill (SpacetimeDB).
- Hiro is the closest shipped "catalog of game systems": one product, many systems, used per game. But it covers metagame, not real-time gameplay.

## Evidence for and against A, B and C

### A. One full template with every system, plus a skill
- **For:** Templates are the shipped entry point. Examples: Godot Project Manager templates [S15](https://docs.godotengine.org/en/latest/community/asset_store/what_is_asset_store.html), Unreal variants [S5](https://dev.epicgames.com/documentation/unreal-engine/variants-in-game-templates), Unity Quickstart after install [S6](https://docs.unity.com/en-us/multiplayer/multiplayer-center.md). The agent gets full code with no dependency step.
- **Against:** I found no engine that ships one template with every system. Unreal splits by genre [S5]. Unity installs only what a game type needs [S6]. Copies get no updates [S10](https://docs.unity.com/en-us/engine/6000.0/manual/packages-list/cus-pkg-development/cus-samples), [S13](https://create.roblox.com/docs/projects/assets/packages.md). Big samples go stale (Boss Room [S11](https://docs.unity3d.com/Packages/com.unity.netcode.gameobjects@2.10//manual/samples/bossroom/bossroom-landing.html); Arena Shooter missing assets [S5], both REPORTED).

### B. Catalog in one place, one skill points to systems
- **For:** The Unity Multiplayer Center is a shipped catalog-router [S6]. Roblox agents search and insert from the Creator Store [S12](https://create.roblox.com/docs/studio/mcp.md). Hiro is one toolkit with about 20 systems [S29](https://heroiclabs.com/docs/hiro/). A Lyra experience enables a listed subset [S4](https://x157.github.io/UE5/LyraStarterGame/Experience) (REPORTED).
- **Against:** One flat index stops scaling. Unreal needed tool search for "hundreds of tools" [S1](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-mcp-in-unreal-editor). Curating a catalog is costly: Godot authors had to re-upload everything [S15]. Installing into a non-fresh project causes conflicts [S6]. If "pull in" means copy, updates stop [S13].

### C. Separate packages, each with research doc and skill, plus a router skill
- **For:** Unreal loads SKILL.md and toolsets per enabled plugin [S1]. SpacetimeDB ships separate skills with a shared always-on core skill that points to them [S21](https://github.com/clockworklabs/SpacetimeDB/tree/master/skills), [S22](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/skills/concepts/SKILL.md). Bevy's ecosystem is many small plugin crates [S20](https://bevy.org/learn/quick-start/plugin-development/).
- **Against:** Nobody splits skills per gameplay system. SpacetimeDB splits by language and layer [S21]. Roblox has one `skill` tool [S12]. Unreal routes in the host (Asset Registry, `GetSkills`, tool search) [S1], not through a hand-written router skill. A router that lists 200 systems has B's flat-index problem again. Per-package versions cost upkeep: Bevy needs version tables [S20], and tools lag behind releases [S19](https://github.com/TheBevyFlock/bevy_cli/releases) (REPORTED). No engine ships design research with packages. They ship API docs and Markdown pages [S25](https://doc.photonengine.com/llms.txt), [S29].

## New options or hybrids
- **H1. Starter + versioned systems + copied samples** (Unity, Godot, Unreal pattern). A thin starter game. Systems as versioned modules. Copy-in samples only for the parts a game is meant to change [S10](https://docs.unity.com/en-us/engine/6000.0/manual/packages-list/cus-pkg-development/cus-samples), [S15](https://docs.godotengine.org/en/latest/community/asset_store/what_is_asset_store.html).
- **H2. Feature manifest** (Lyra, Game Features). The game lists features to enable. Features plug in through a small core surface [S3](https://dev.epicgames.com/documentation/en-us/unreal-engine/game-features-and-modular-gameplay-in-unreal-engine), [S4](https://x157.github.io/UE5/LyraStarterGame/Experience).
- **H3. Data-driven recommender** (Multiplayer Center). Game type → locked essentials + optional extras. Install, then show a quickstart that adapts [S6](https://docs.unity.com/en-us/multiplayer/multiplayer-center.md). A router skill could read this table instead of prose.
- **H4. Host-indexed skills** (Unreal). Each package carries `Skills/`. The host lists only skills from enabled packages. Tools sit behind list → describe → call [S1](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-mcp-in-unreal-editor).
- **H5. Always-on core rules + layer skills + benchmark** (SpacetimeDB) [S21](https://github.com/clockworklabs/SpacetimeDB/tree/master/skills), [S22](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/skills/concepts/SKILL.md), [S23](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/docs/llms/oneshot-summary.md).
- **H6. Linked copy** (Roblox Packages). Copy with a link. Auto-updates until edited. Per-copy config survives [S13](https://create.roblox.com/docs/projects/assets/packages.md). Fits data and content. Weak for code that agents will edit.
- **H7. Version-pinned agent docs** (Photon). Docs tell agents which version to target and which products are preview [S25](https://doc.photonengine.com/llms.txt).

## Hype to discount
- Unity blog: "highly accurate, context-aware assistance" and "You no longer have to rewrite AI-generated code to make it fit your architecture". No data or examples [S9](https://unity.com/blog/mcp-servers-game-development). OPINION (vendor).
- Epic's 5.8 post says MCP enables "automated asset creation, testing, optimization, and project interaction across core engine systems" [S2](https://forums.unrealengine.com/t/unreal-engine-5-8-released/2729274). Meanwhile the docs mark it Experimental [S1](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-mcp-in-unreal-editor), and a user says it does nothing until toolset registries are enabled by hand [S2].
- SpacetimeDB's "+29.0 percentage points". Vendor-run. 13 runs, 1-4 per model. Method and prompt parity not stated. Features 13-15 score 0.00 with no reason given [S23](https://raw.githubusercontent.com/clockworklabs/SpacetimeDB/master/docs/llms/oneshot-summary.md).
- Community tool counts: Rekall "480+ tools", a Godot MCP with "300+ tools", unity-mcp with 80 tools and 42 resources [S31](https://forums.unrealengine.com/t/marius-store-rekall-ai-coding-assistant-plugin-claude-cursor-windsurf/2719545), [S17](https://mcpservers.org/servers/Coding-Solo/godot-mcp). Counts say nothing about quality. Unreal hides its tools behind search.
- Third-party "agent readiness" grades (e.g., Heroic Labs "Grade D") come from an unknown method. REPORTED.
